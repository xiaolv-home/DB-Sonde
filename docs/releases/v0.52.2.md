## 这一版改了什么

**问题修复**

- MySQL、Oracle、SQLite 的块注释遇到第一个 `*/` 就结束(只有 PostgreSQL / ClickHouse 能嵌套)。原来一律按嵌套处理,注释里再写一个 `/*`,后面的语句就全被当成注释。
- 指标中心预览派生指标(指标 ÷ 指标)时,分子分母各自按所选日期取数;原来总是整段历史的比值。

**测试**

- 把拼 SQL、拆语句、改单元格、数据集、看板取数、指标编译这几个核心模块逐处改坏,检查测试能不能发现。第一轮 511 处改动里有 183 处测试发现不了,这一版把缺口补上了(上面两个问题就是这么找出来的)。

**文档**

- README 和开发文档按现在的功能重写;每个版本的更新说明放在 [docs/releases](https://github.com/xiaolv-home/DB-Sonde/tree/main/docs/releases),发布页会自动带上。
