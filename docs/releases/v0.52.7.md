# DB Sonde 0.52.7

- **安全与沙箱加固**：`pip` 与 `ruff` 调用补齐包名白名单、工作区路径门禁与 `--` 参数分隔；监控中心探测改为逐跳校验重定向目标并收紧 `frame-ancestors` 域名匹配；内置模型启动强制校验 `~/.db-sonde/models` 目录与 `.gguf` 文件。
- **后台进程与流式稳定性提升**：退出应用自动清理本地 `llama-server`、`jedi` 补全服务与运行中的 Python 脚本；macOS / Linux 停止脚本改为整组终止子孙进程；Python 输出增加单块限长与批量事件合并，大量 `print` 不再卡界面；代码补全与流式模型代理补齐空闲超时熔断。
- **数据精度与手动事务增强**：MySQL `JSON` 与 PostgreSQL `JSONB` 嵌套的 64 位雪花 ID 自动按精确字符串传输并在编辑写回时拦截裸大数精度丢失；手动提交事务内单条语句支持 `SAVEPOINT` 错误隔离与超时控制；支持渲染 `INSERT / UPDATE / DELETE ... RETURNING` 结果集；区分看板字面量 `"NULL"` 与 SQL `IS NULL`。
- **架构与持久化升级**：看板在线渲染与离线 HTML 导出共享同一套数值换算、聚合与自由准星实现；链路画布迁移至应用配置目录原子 JSON 存储（自动兼容旧本地画布，解除 5MB 容量上限）；全部本地配置与资产读写命令移出界面主线程。
