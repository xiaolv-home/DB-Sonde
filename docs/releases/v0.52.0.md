## 这一版改了什么

**「数据资产」瘦身:删掉 ETL 中心、调度中心和血缘图**

这三块用得少、用着也别扭,整块拿掉。现在「数据资产」里是:数据集、指标、链路画布、监控中心。

- 链路画布保留,成为「数据资产」里单独的一项;「从血缘添加」改成「从数据库添加表」(选连接和库,搜表、勾几张一次加进来)。
- 表详情(原来的「360° 全景」)只留数据新鲜度和建在这张表上的指标,右键表选「新鲜度与指标」打开。
- 升级后原来的 ETL 接入源、调度连接、血缘记录不再显示;要接调度平台,直接在「监控中心」把它的网页嵌进来。

**数据集重做**

- 「数据集」改成卡片列表(来源、几列、几个看板在用),点开是铺满窗口的编辑器:左边是数据集列表,右边从上往下是「数据从哪来 → 字段 → 预览数据」。
- 关联不再拖卡片连线,写成一句话:「左连接 X 按 X.id = Y.x_id」,每处都是下拉,可以多条件、且 / 或、比较符。
- 加表时先把关联猜好:已有表里的 `xxx_id` 指向新表的优先;还会按已有表里的 `xxx_id` 推荐下一张该连的表。
- 字段随来源自动识别,不用再点「探测字段」;一行一个字段,勾选保留、改显示名、点一下切维度 / 度量、设默认汇总,按表分组可折叠。
- ⌘S 保存;有没保存的改动时离开会先问。
