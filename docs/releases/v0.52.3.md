## 这一版改了什么

**没有主键的表也能改、能增删行**

以前表没有主键,整张表只读,连增行都不行。现在和 DBeaver 一样:没有主键时,按整行所有列的值定位要改 / 删的那一行。

- 增行不需要主键,直接可以加。
- 改单元格、删行按整行的值找那一行;值是 NULL 的列也能对上。大文本、二进制、JSON、单精度浮点这类值对不准的列不拿来比。
- 有两行一模一样时:删行只删其中一行;改单元格会被拦下并撤销(没法只改其中一行,这种行请用 SQL 改)。
- 视图和 ClickHouse 表仍然只读。

**删行更可靠**

- 每一条删除都核对是不是正好删掉了一行。那一行已经被别人改过或删掉时会报错,并整批撤销;以前删不到也提示成功,界面上那行消失了,库里其实还在。
- 「命中行数不对」的提示改成了中文,并说明是哪种情况。

**其他**

- 跑检查时不再在系统临时目录留下文件;删掉一个已经不用的打包脚本。
