## 这一版改了什么

全是问题修复,来自对 0.52.0 和几个核心功能(查询执行、数据页编辑、看板取数)的三轮排查。

**数据集**

- 改来源后重新识别字段,不再丢掉计算字段和分组字段。
- 写 SQL 时不再边打字边执行:离开 SQL 框或点「识别字段」才去认。
- 连续加两张推荐的表,不再丢掉前一张。
- 从「写 SQL」切回「选表关联」会先确认(SQL 会丢);新建后没动过的数据集离开不再提示未保存。

**查询执行**

- Oracle 的 PL/SQL 块(`BEGIN … END;`、`CREATE PROCEDURE` 等)不再被内部的分号切碎;整段算一条,写到单独一行的 `/` 结束。
- MySQL 支持 `DELIMITER $$` 写存储过程。
- 脚本末尾只剩一行注释时,不再把它当成一条语句去执行(Oracle 上会报 ORA-00900)。

**数据页**

- 右键菜单叠加筛选条件时,旧条件加括号:原来 `a OR b` 再叠 `AND c` 会变成 `a OR (b AND c)`,整列赋值也会改到不该改的行。
- 往下滚动翻页时按主键稳定排序,不再出现重复行或漏行。
- 删除连接要先确认;手动提交模式下断开连接,会先提示未提交的修改将被回滚。

**看板**

- Oracle 上选数据日期不再报 ORA-01861。
- 字段的筛选候选值不再只剩组件「前 N 名」那几个。
- 数据集里标成「不保留」的日期列,不再被拿来做日期条件。

**导出**

- JSON 导出时,重名的列(`SELECT * FROM a JOIN b` 里的两个 `id`)依次加 `_2`、`_3`,不再互相覆盖。
- 链路画布导出动图 / 视频时,流动速度和画布上一致。
